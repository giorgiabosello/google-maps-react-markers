The first `<GoogleMap>` on the page configures the Maps JavaScript API. Later maps reuse it, and their loader props are ignored (with a warning in development if the key differs).

## Hooks

| Hook                    | Returns                                                  |
| ----------------------- | -------------------------------------------------------- |
| `useMap()`              | `google.maps.Map \| null`. Throws outside `<GoogleMap>`. |
| `useMapsLibrary(name)`  | the library, or `null` until loaded.                     |
| `useGoogleMapsStatus()` | `'loading' \| 'ready' \| 'error'`.                       |

## Types

All prop and event types are exported: `GoogleMapProps`, `MarkerProps`, `MapControlProps`, `MapChangeEvent`, `MapLoadEvent`, `MapEventProps`, `MarkerAnchor`, `MarkerAnchorPreset`, `MarkerDragHandler`, `MarkerRenderer`, `GoogleMapsLoaderOptions`, `GoogleMapsStatus`, `LatLngLiteral`, `BBox`.
